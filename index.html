How the RAG Pipeline Works

1. User submits a natural language text query from this clean frontend.
2. The query is transmitted to your backend RAG server via JSON/Text HTTP POST.
3. The backend retrieves matching records from the Hospital DBMS (Patients, Wards, Appointments, Prescriptions, Lab Reports) using vector search and SQL joins.
4. The LLM generates a grounded clinical or administrative response with table citations and returns it to be rendered here.
